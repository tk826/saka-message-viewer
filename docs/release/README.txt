坂道メッセージビューア
======================

colmsg で保存したメッセージ・画像・動画・音声を、ブラウザで閲覧・検索するツールです。

■ 使い方

1. この zip を好きな場所に展開する
   (日本語や空白を含むフォルダでもよい。展開したフォルダごと移動してもよい)
2. message-viewer.exe をダブルクリックする
   黒いウィンドウが開いたままになります。これがサーバです(使っている間は閉じない)
3. ブラウザで http://localhost:8000/ を開く
4. 初回は設定画面が開くので、メッセージ保存フォルダ(colmsg の保存先)を指定する
   指定するとすぐに取り込みが始まります

終了するときは、黒いウィンドウを閉じるか Ctrl+C を押します。

■ 初めて起動するとき

「Windows によって PC が保護されました」と表示された場合は、
「詳細情報」→「実行」を押してください(署名の無い exe のため表示されます)。

■ フォルダの中身

message-viewer.exe   サーバ本体(これだけで動きます。インストール不要)
config.json          設定(ポート番号など。保存フォルダは画面から指定する)
static\              画面
MoveFiles.bat        保存フォルダの整形(任意)
data\                初回起動時に作られる。取り込んだ内容・お気に入り・ログ(server_log.txt)

■ 更新するとき

サーバを止めてから、新しい版の zip の message-viewer.exe と static\ で上書きしてください。
data\ (取り込んだ内容・お気に入り・コメント)はそのまま使えます。
config.json は上書きしないでください(上書きすると保存フォルダの指定が消えます。
その場合も画面から指定し直せば、data\ の内容はそのまま使えます)。

■ 動画のサムネイル(任意)

ffmpeg.exe を message-viewer.exe と同じフォルダに置くと、動画のサムネイルも作られます。
詳しくは https://github.com/tk826/saka-message-viewer の docs/ffmpeg.md を参照してください。
